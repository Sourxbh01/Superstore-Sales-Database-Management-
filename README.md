# 📊 Superstore Sales Analysis using SQL & Excel

## 📌 Project Overview

This project presents an end-to-end analysis of a retail Superstore dataset using **SQL** for data analysis and **Microsoft Excel** for data visualization.

The goal is to transform raw sales data into meaningful business insights by performing data cleaning, exploratory data analysis (EDA), and answering business-related questions. The final results are presented through an interactive Excel dashboard.

---

## 🎯 Objectives

* Import and manage retail sales data in SQL
* Clean and prepare the dataset for analysis
* Explore sales, profit, customer, and product performance
* Solve real-world business problems using SQL queries
* Build an interactive Excel dashboard to visualize key metrics
